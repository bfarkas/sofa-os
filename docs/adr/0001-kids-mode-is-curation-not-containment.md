# Kids Mode is curation, not containment

A sandboxed Tizen app cannot replace Samsung Home, so the Home key always gets a child out of Sofa Home, and provider apps govern their own catalogs. We therefore treat Kids Mode as a calm, approved front door with a daily Watch Allowance, and rely on provider-side controls for real restriction. The PIN is a light deterrent, and we deliberately omit lock-style enforcement such as per-profile cache partitioning, per-request media authorization and offline Kids Mode rules, because the boundary cannot back them up.

The Watch Allowance clock lives on the Server and the TV is switched off through Home Assistant, so the limit still applies after a child leaves Sofa Home.
